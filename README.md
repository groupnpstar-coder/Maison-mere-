# Maison Mère

Ton argent ne bouge pas sans ton accord.

Application de test : comptes, annuaire de professionnels, projets par étapes avec argent bloqué (fictif), photos, messages, litiges, avis, marché des matériaux, estimateur de prix, gardiens et espace admin.

- `index.html` : l'application
- `config.js` : la configuration Firebase et les emails admin
- `firestore.rules` : les règles de sécurité à coller dans Firebase (Firestore › Règles)

Version de test : aucun vrai paiement.
